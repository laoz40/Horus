# Workout Tracker

Simple workout tracker web app for tracking workouts and fitness progress. Slowly learning to code, with help from AI. This project will eventually be an actual app.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)

### Installation

1. Clone the repository
   ```bash
   git clone [https://github.com/laoz40/workout-tracker.git](https://github.com/laoz40/workout-tracker.git)
   cd workout-tracker

2. Install dependencies
   ```bash
   npm install

#### 📦 Dependencies

- TypeScript - For type-safe JavaScript

## 🛠️ Development

### Available scripts

#### Development Mode (watch for changes)
```bash
npm run dev
```
Automatically compiles TypeScript files on save.

#### Build Once
```bash
npm run build
```
Compiles TypeScript into the /dist directory.
