# Workout Tracker

Simple workout tracker web app for tracking workouts and fitness progress. Slowly learning to code, with help from AI. This project will eventually be an actual app.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/laoz40/workout-tracker.git
   cd workout-tracker
   ```

2. Install dependencies

   ```bash
   npm install
   ```

#### 📦 Dev Dependencies

- TypeScript - For type-safe JavaScript
- Biome - For code formatting and linting
- Concurrently - For running multiple scripts simultaneously
- Live Server - For local development server with live reload

## 🛠️ Development

### Available Scripts

#### Development Mode (watch for changes)

```bash
npm run dev
```

Runs TypeScript compiler in watch mode and starts a live development server that automatically reloads when you make changes to HTML, CSS, or JavaScript files.

#### Check and Fix Code

```bash
npm run check
```

Runs Biome to check and automatically fix linting and formatting issues in your code.
